# Community event evidence checklist

## Label the metric

- Application — submitted interest; not attendance.
- Approval — organizer accepted the application; not attendance.
- Registration — attendee reserved a place; not attendance.
- Verified check-in — attendee was recorded at the event.
- Completion — attendee finished the defined workshop outcome.
- Reported attendance — organizer estimate without individual verification.

## Minimum evidence record

- Event or workflow name
- Date and city or online format
- Metric name and value
- Collection method
- Source link or local export
- Known limitation
- Generated timestamp

## Privacy gate

Before adding a field, answer:

1. Is the field necessary for an operational decision?
2. Can the workflow use a category instead of the raw value?
3. Who can view it?
4. When is it deleted?
5. Can a synthetic example demonstrate the feature instead?

If these questions are unanswered, do not add the field.
